# HR LINE Chatbot (Gemini) + หน้า Admin

บอท LINE ตอบคำถามพนักงานเรื่องกฎเกณฑ์บริษัท โดย HR แก้เนื้อหาผ่านหน้า Admin (ไม่มีหน้าเว็บสำหรับพนักงาน พนักงานถามผ่าน LINE)

- `/admin` หน้าสำหรับ HR เข้าสู่ระบบด้วยรหัสผ่านเพื่อเพิ่ม/แก้ไข/ลบ/เรียงลำดับหัวข้อทีละรายการ (บันทึกทันที ไม่มีปุ่มบันทึกรวม) (`/` จะ redirect มาที่นี่)
- `/webhook` Webhook ของ LINE Messaging API บอทอ่านข้อมูลที่บันทึกในหน้า Admin โดยตรง บันทึกแล้วมีผลทันที
  ถ้าไม่พบข้อมูลที่เกี่ยวข้อง จะตอบว่า "ยังไม่มีข้อมูลนี้ค่ะ"
- `/health` ตรวจสถานะและรายการ env ที่ยังขาด

## Deploy บน Railway

1. Push โปรเจกต์ขึ้น GitHub แล้ว Railway → New Project → Deploy from GitHub repo
2. ตั้ง Variables (ดู `.env.example`):
   - `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN` จาก LINE Developers Console
   - LLM อย่างใดอย่างหนึ่ง:
     - API แบบ OpenAI-compatible: `LLM_BASE_URL` (เช่น `https://ai.thirx.com/v1`), `LLM_API_KEY`, `LLM_MODEL` (ถ้าตั้ง จะใช้ตัวนี้ก่อน)
     - หรือ Gemini: `GEMINI_API_KEY` จาก Google AI Studio
   - `ADMIN_PASSWORD` รหัสผ่านเข้าหน้า `/admin`
   - (ไม่บังคับ) `DATA_DIR` ถ้าแนบ Volume ระบบใช้ path ของ Volume ให้อัตโนมัติ
3. **เพิ่ม Volume** (ที่เก็บข้อมูลถาวร): ที่ service กด Add Volume (หรือคลิกขวาบนพื้นที่ canvas → Volume) แล้วตั้ง Mount path เป็น `/data`
   ถ้าไม่มี Volume ข้อมูลที่ HR บันทึกจะหายทุกครั้งที่ deploy ใหม่
4. Settings → Networking → Generate Domain
5. LINE Developers → Messaging API → Webhook URL = `https://<domain>/webhook` → Verify แล้วเปิด "Use webhook"
   (ปิด Auto-reply messages ใน LINE Official Account Manager ด้วย)

## รูปแบบเนื้อหา

ในช่องรายละเอียด ขึ้นบรรทัดใหม่เพื่อแยกย่อหน้า และขึ้นต้นบรรทัดด้วย `- ` เพื่อทำเป็นรายการ

## โหมด AI (Gemini / LLM)

ในหน้า Admin มีการ์ด "โหมด AI" ให้สลับระหว่าง **Gemini** กับ **LLM** (API แบบ OpenAI-compatible) ค่าที่เลือกใช้กับทั้งบอท LINE และตัวช่วยเขียน มีผลทันที ไม่ต้อง deploy ใหม่ และเก็บบน Volume (`settings.json`)
ปุ่ม "ทดสอบการเชื่อมต่อ" ใช้เช็คว่าโหมดที่เลือกตอบได้จริง (key, URL, ชื่อโมเดลถูกต้อง)

- สลับได้เฉพาะโหมดที่ตั้ง key ไว้ใน Variables แล้ว (`GEMINI_API_KEY` สำหรับ Gemini, `LLM_BASE_URL` + `LLM_API_KEY` สำหรับ LLM)
- ถ้ายังไม่เคยเลือก จะใช้ LLM ก่อน (ถ้าตั้งไว้) แล้วค่อยใช้ Gemini ถ้าโหมดที่เลือกไว้ถูกถอด key ออก ระบบจะถอยไปใช้โหมดที่ยังตั้งค่าอยู่

## AI ช่วยเขียนข้อความ

ในหน้าต่างเพิ่ม/แก้ไขหัวข้อ กด "ให้ AI ช่วยเขียน" พิมพ์ข้อมูลดิบสั้นๆ (เช่น ลาพักร้อน 10 วันต่อปี แจ้งล่วงหน้า 3 วัน) แล้วกด "สร้างข้อความ" AI จะร่างข้อความรายละเอียดลงในช่องให้
ติ๊ก "ใช้เนื้อหาในช่องรายละเอียดเป็นฐาน" เพื่อให้ AI ปรับปรุงข้อความเดิมแทนการเขียนใหม่ และกด "เลิกทำ" เพื่อย้อนกลับได้

- ใช้ LLM ตัวเดียวกับบอท (`LLM_*` หรือ `GEMINI_API_KEY`) ใช้ได้เฉพาะผู้ดูแลที่ล็อกอิน จำกัด 30 ครั้งต่อชั่วโมงต่อ IP
- AI ถูกสั่งให้เขียนจากข้อมูลที่ให้เท่านั้น และใส่ `[ระบุ: ...]` แทนข้อมูลที่ไม่มี แต่ยังอาจผิดพลาดได้ ต้องตรวจทานตัวเลขและเงื่อนไขก่อนบันทึกทุกครั้ง
- ข้อความที่ AI สร้างยังไม่ถูกบันทึกจนกว่าจะกด "บันทึกหัวข้อ"

## รูปภาพประกอบ

แต่ละหัวข้อแนบรูปได้สูงสุด 4 รูป (เลือกไฟล์ในหน้าต่างเพิ่ม/แก้ไขหัวข้อ) เบราว์เซอร์จะย่อรูปเป็น JPEG ไม่เกินประมาณ 900 KB ให้อัตโนมัติ
เมื่อบอทตอบโดยใช้หัวข้อที่มีรูป จะส่งรูปนั้นตามไปใน LINE ด้วย (รวมไม่เกิน 4 รูปต่อคำตอบ)

- รูปเก็บบน Volume (`uploads/`) และเปิดดูได้โดยผู้ที่มีลิงก์ (ชื่อไฟล์สุ่ม เดายาก) อย่าแนบรูปที่เป็นความลับ
- LINE ต้องดึงรูปผ่าน https ระบบใช้โดเมนของเว็บเองโดยอัตโนมัติ ถ้าต้องการกำหนดเอง ตั้ง `PUBLIC_BASE_URL` (เช่น `https://your-domain.up.railway.app`)
- เมื่อมีหัวข้อที่มีรูป ระบบจะเพิ่มกติกาหนึ่งข้อใน System Prompt ให้โมเดลระบุเลขหัวข้อที่ใช้ตอบ (ถ้าไม่มีรูปในระบบ prompt จะเหมือนเดิมทุกประการ)
- รูปที่อัปโหลดแล้วไม่ได้ผูกกับหัวข้อใด จะถูกลบอัตโนมัติ
